# Capability Map: Aquí Suena (by 17Labs)

Product: Aquí Suena — listen and discover shops. Developed and operated by 17Labs.

## Product modules

| Module id          | Responsibility                                                                                                                                  | Depends on                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| radio-playback     | Persistent audible player with autoplay, top/bottom position, 403 fallback; never disappears                                                    | —                                               |
| business-directory | Listings: name, category, products + prices, photos, phone, email, address, hours, open/closed, delivery                                        | —                                               |
| memberships        | Three tiers (Comunidad free, Oficios & Servicios, Comercios & Catálogo): listing limits, photos, priority, audio-spot and push-send eligibility | business-directory                              |
| owner-portal       | Owner platform to create/edit listings, hours, photos, products; view flyers, invoice PDFs and spot previews; paywall-gated                     | business-directory, memberships                 |
| ads-display        | Carousel of sponsors during listening, paid priority, tap → listing sheet; audio never stops                                                    | radio-playback, business-directory, memberships |
| radio-spots        | Recorded spots rotated every X songs — Comercios & Catálogo only, flag off until launch                                                         | radio-playback, memberships                     |
| radio-origin       | Own station from scratch (post-V1)                                                                                                              | radio-playback                                  |

Build order: radio-playback → business-directory → memberships → owner-portal → ads-display → radio-spots → radio-origin (future)

## Platform capabilities (shipped in `packages/*`)

| Module id           | Responsibility                                                                                                                                                                                                                                                                                                                                                                             | Depends on                                     |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------- |
| accounts-auth       | Accounts, `ctx.user` identity (Supabase Auth seam) and persisted `locale`; signup/verification email pending                                                                                                                                                                                                                                                                               | —                                              |
| billing             | Subscriptions (cancel, plan change, grace period, reminders), Conekta payments (card/cash/SPEI) and CFDI invoicing through a PAC: stamp, XML/PDF/acuse archive in R2 with recovery of missing archives by provider id, email delivery, history with signed downloads, cancellation with motive `01` (substitution), `02` and `03`, and a scheduled sweep for receiver acceptance           | memberships, business-directory, accounts-auth |
| transactional-email | 11 rendered templates (es-MX/en) behind an `EmailSender` port; live triggers are the subscription lifecycle (cancel, plan downgrade, renewal failed, grace expired), renewal reminders, payment pending/receipt and CFDI delivery; account welcome and verification wait on signup                                                                                                         | accounts-auth, billing                         |
| account-lifecycle   | Lazy account provisioning keyed by the Supabase session, email re-sync, and owner-initiated deletion that keeps a fiscal tombstone                                                                                                                                                                                                                                                         | accounts-auth, billing, media-storage          |
| media-storage       | Server-generated `media/v1` keys with account/business scope, business ownership and plan entitlement checks, presigned R2 uploads, idempotent confirm, magic-byte and GPS-EXIF validation, MP3 duration checks, versioned CORS, owner signed reads, public listing reads, listing links with retention purge and orphan sweep, D1 media rows, explicit `503` when storage is unconfigured | —                                              |
| support-chatbot     | Read-only RAG over plans, the directory, public listing media and temporary listener photo queries (multimodal, free tier; no paid AI Search/Images)                                                                                                                                                                                                                                       | memberships, business-directory                |
| admin-ops           | Token-guarded seed and maintenance endpoints (plans, stations, vectors, retention purge)                                                                                                                                                                                                                                                                                                   | billing, radio-playback                        |
| i18n                | es-MX/en dictionaries shared by web, mobile and desktop                                                                                                                                                                                                                                                                                                                                    | —                                              |

Shared stack: React + Next.js + React Native + React Native Web + Expo + Tamagui (components + styling) + tRPC + TanStack Query + Drizzle + SQLite/D1 + Hono + Valibot + Biome (lint + format, replaces ESLint/Prettier)
